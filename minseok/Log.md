이번 주에는 팀원이 올린 PR을 검토하고, 코드에서 발견한 오류를 확인하여 수정 커밋을 작성하였다.

일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

Dart 코드를 처음 접해 초반에는 문법과 코드 구조가 익숙하지 않아 다소 혼란스러웠다.
하지만 기존에 사용해 본 언어들과 기본적인 코드의 틀과 흐름이 비슷한 부분이 많아, 코드를 직접 읽고 수정하면서 빠르게 적응할 수 있었다.

내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

잘한 점은 익숙하지 않은 Dart 코드임에도 부담을 갖기보다 직접 코드를 분석하고 오류를 찾아 수정까지 진행한 것이다. 또한 팀원의 PR을 검토하면서 코드의 문제점을 확인하고 수정 커밋까지 작성해 실제 작업에 기여할 수 있었다.

아쉬웠던 점은 Dart 문법과 프로젝트 구조를 조금 더 미리 학습했다면 PR 리뷰와 오류 수정 과정에서 더 빠르고 정확하게 판단할 수 있었을 것이라는 점이다. 앞으로는 리뷰 과정에서 이해가 부족했던 부분을 따로 정리하며 학습할 예정이다.
